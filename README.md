# Team Project & Task Management REST API

A REST API built with Python and FastAPI for managing projects, tasks, users, and comments.

## Day 1 — FastAPI & REST Fundamentals

### Technologies
- Python 3.13
- FastAPI
- Uvicorn
- Pydantic

### Implemented
- Health Check API
- Project CRUD APIs
- Pydantic validation
- HTTP status codes
- Swagger UI
- OpenAPI documentation

### API Documentation

Swagger:
`http://127.0.0.1:8000/docs`

OpenAPI:
`http://127.0.0.1:8000/openapi.json`

### Database

Currently using a temporary in-memory Python list.

PostgreSQL and SQLAlchemy will be implemented in Day 2.
